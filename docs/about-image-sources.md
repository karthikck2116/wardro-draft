# About page image sources

- `about-hero-family.png` reuses the approved Wardro family-bedroom image
  already present in the project.
- `designed-for-indian-homes.png` reuses an existing Wardro product image.
- `homecraft-factory-temporary.png` is an AI-generated temporary visual created
  for the production-floor layout because no approved Home Craft factory
  photography was available in the workspace.

Replace the temporary factory image with approved Home Craft photography before
using the page as documentary proof of a specific facility. The section markup
and image path are intentionally isolated to make that replacement simple.
